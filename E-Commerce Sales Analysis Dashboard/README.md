# E-Commerce Sales Analysis Dashboard (Excel BI & Slicer Automation)

## Project Overview
This project presents an interactive Business Intelligence E-Commerce Sales Dashboard developed in Microsoft Excel. It provides comprehensive performance tracking across total sales, profits, order volumes, profit margins, geographic distribution, and customer segments.

The workbook is structured with a clean separation of concerns, featuring dedicated layers for raw datasets, cleaned data tables, dynamic Pivot Tables, and an executive front-end reporting interface.

## Business Insights & Visual Analytics

### 1. Sales and Profit Analysis (Line & Bar Combination Chart)
- Tracks monthly revenue vs. profit trajectories across the year (January to December).
- Highlights peak sales months and identifies seasonal performance trends.

### 2. Category Wise Sales Share % (Donut Chart)
- **Technology:** 36.40% market share.
- **Furniture:** 32.30% market share.
- **Office Supplies:** 31.30% market share.
- *Business Takeaway:* Balanced revenue distribution across all three major product categories with Technology leading slightly.

### 3. Segment Wise Sales (Donut Chart)
- **Consumer:** Dominates order volume and total revenue contribution.
- **Corporate & Home Office:** Form the secondary and tertiary revenue pillars.

### 4. Category Wise Profit & Top 5 Subcategories
- Evaluates profitability breakdown per category.
- Highlights top-performing subcategories including **Phones**, **Chairs**, **Storage**, **Tables**, and **Binders**.

### 5. Sales by State (Geographic Heatmap / Chart)
- Visualizes state-by-state sales distribution across the United States, pinpointing top-performing regions.

## Interactive Slicer Filters
The dashboard features an advanced **Slicer Filter Panel** enabling dynamic cross-filtering by:
- **Region:** Central, East, South, West
- **Category:** Furniture, Office Supplies, Technology
- **Segment:** Consumer, Corporate, Home Office
- **State:** Quick filtering across various states (e.g., Nevada, New Jersey, New York, North Carolina, Ohio, etc.)

## Technical Architecture & Structure
The workbook is built across organized sheets:
- **Dashboard:** Front-end interactive visual interface with modern KPI cards and slicers.
- **Analysis / Pivot:** Backend calculation engine containing dynamic Pivot Tables and summary metrics.
- **Clean Data:** Structured and prepped dataset ready for reporting.
- **Raw Data:** Original unmodified source dataset.

## Repository Files
- `Ecommerce Sales Analysis.xlsb` — Macro-enabled interactive Excel workbook containing the full dashboard and data model.
- `README.md` — Project documentation and breakdown.

## How to Use
1. Download the Excel file from this repository.
2. Open the file in Microsoft Excel and select **Enable Content** if prompted for macros/activeX.
3. Use the right-side **Slicer Filters** to dynamically slice and dice the data by region, category, segment, or state.
4. Use the navigation tabs at the bottom to explore the raw data, clean data, and pivot sheets.
